# Match Call Test (Android)

تطبيق أندرويد أصلي لتجربة المكالمات على الشبكة المحلية مع Asterisk عبر `ws://` — بدون HTTPS في المتصفح.

## المتطلبات

- Android Studio Hedgehog+ أو سطر أوامر Gradle
- جهاز/محاكي **minSdk 24** (Android 7+)
- نفس شبكة LAN مع خادم Match
- من لوحة التحكم → الاتصال → **ضبط**: تفعيل إعلان الاكتشاف واختيار منفذ من `18760–18769`

## البناء (جاهز للتحميل من الخادم)

```bash
# من جذر المستودع — ينسخ APK إلى var/comms/android/match-call-test.apk
bash infra/scripts/build-android-call-test.sh
```

متطلبات السكربت: JDK 17 و Android SDK تحت `/opt/android-sdk` (platforms;android-34).

بعد البناء يظهر زر التحميل في لوحة الاتصال وصفحة `/call` (ما لم يُخفَ من تبويب ضبط).

## الاستخدام

1. فعّل الإعلان من تبويب **ضبط** في قسم الاتصال.
2. افتح التطبيق → **بحث عن الخادم**.
3. اختر الخادم المكتشف → أدخل رقماً داخلياً وكلمة مروره من لوحة Match → **تسجيل**.
4. على جهاز آخر (أو `/call`) سجّل الرقم الثاني ثم اتصل.

## بروتوكول الاكتشاف

- التطبيق يبث `MATCH_DISCOVER` على UDP `18760–18769`
- الخادم يرد: `MATCH_BEACON {json}` فيه `wsUrl` و `sipDomain`

## ملاحظات

- الإشارة: `ws://HOST:8088/ws` (Asterisk)
- الصوت: WebRTC (DTLS-SRTP) كما في صفحة `/call`
- هذا أداة تجربة داخل المستودع وليست تطبيقاً للمتجر
