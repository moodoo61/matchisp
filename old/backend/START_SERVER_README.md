# دليل تشغيل السيرفر الخلفي

## 📋 ملفات BAT المتوفرة

تم إنشاء عدة ملفات BAT لتسهيل إدارة وتشغيل السيرفر الخلفي:

### 1️⃣ **setup.bat** - الإعداد الأولي
استخدم هذا الملف **عند تشغيل المشروع لأول مرة**

**المهام:**
- ✅ إنشاء البيئة الافتراضية (Virtual Environment)
- ✅ تثبيت جميع المتطلبات من `requirements.txt`
- ✅ إعداد قاعدة البيانات (migrations)

**طريقة الاستخدام:**
```bash
انقر نقراً مزدوجاً على: setup.bat
```

---

### 2️⃣ **start_server.bat** - تشغيل السيرفر (مع فحص شامل)
الملف الرئيسي لتشغيل السيرفر مع فحص كامل للنظام

**المهام:**
- ✅ التحقق من Python والبيئة الافتراضية
- ✅ التحقق من المتطلبات وتثبيتها إذا لزم
- ✅ تطبيق migrations الجديدة
- ✅ جمع الملفات الثابتة (static files)
- ✅ تشغيل السيرفر على المنفذ 8000

**طريقة الاستخدام:**
```bash
انقر نقراً مزدوجاً على: start_server.bat
```

**الوصول للسيرفر:**
- http://127.0.0.1:8000
- http://localhost:8000

---

### 3️⃣ **quick_start.bat** - تشغيل سريع
لتشغيل السيرفر مباشرة بدون فحوصات (للاستخدام اليومي)

**طريقة الاستخدام:**
```bash
انقر نقراً مزدوجاً على: quick_start.bat
```

---

### 4️⃣ **create_admin.bat** - إنشاء مستخدم مشرف
لإنشاء حساب مشرف للوصول إلى لوحة التحكم Django Admin

**طريقة الاستخدام:**
```bash
انقر نقراً مزدوجاً على: create_admin.bat
```

**بعد الإنشاء:**
- يمكنك الدخول إلى: http://127.0.0.1:8000/admin
- استخدم اسم المستخدم وكلمة المرور التي أنشأتها

---

## 🚀 البدء السريع

### المرة الأولى:
1. شغل `setup.bat` (مرة واحدة فقط)
2. شغل `create_admin.bat` لإنشاء حساب مشرف
3. شغل `start_server.bat` لتشغيل السيرفر

### الاستخدام اليومي:
- فقط شغل `quick_start.bat` أو `start_server.bat`

---

## 🛠️ المتطلبات

- **Python 3.8+** مثبت على النظام
- يفضل Python 3.10 أو أحدث

**للتحقق من نسخة Python:**
```bash
python --version
```

---

## 📌 ملاحظات مهمة

### إيقاف السيرفر:
- اضغط `Ctrl + C` في نافذة الأوامر

### إعادة تشغيل السيرفر:
- أوقف السيرفر ثم شغله مرة أخرى

### في حالة حدوث مشاكل:
1. تأكد من تثبيت Python بشكل صحيح
2. شغل `setup.bat` مرة أخرى
3. احذف مجلد `venv` وشغل `setup.bat` من جديد

---

## 🔧 أوامر إضافية يدوية

إذا أردت تشغيل أوامر Django يدوياً:

### تفعيل البيئة الافتراضية:
```bash
venv\Scripts\activate
```

### تطبيق migrations:
```bash
python manage.py makemigrations
python manage.py migrate
```

### تشغيل السيرفر:
```bash
python manage.py runserver
```

### إنشاء مستخدم مشرف:
```bash
python manage.py createsuperuser
```

## 📦 المكونات المثبتة

- Pillow (معالجة الصور)
