# تعليمات إعداد غرف Matrix

## الطريقة السريعة

بعد إعداد الرابط والمستخدم وكلمة المرور في Django Admin، قم بتشغيل الأمر التالي:

```bash
cd backend
python manage.py setup_matrix
```

## الخيارات المتاحة

### 1. اختبار الاتصال فقط:
```bash
python manage.py setup_matrix --test-only
```

### 2. إعادة إنشاء جميع الغرف (حتى الموجودة):
```bash
python manage.py setup_matrix --force
```

## ما سيفعله الأمر

1. ✅ اختبار الاتصال بسيرفر Matrix
2. ✅ اختبار تسجيل الدخول (إن وجدت بيانات الإدارة)
3. ✅ إنشاء غرف Matrix لجميع القنوات النشطة
4. ✅ ربط الغرف مع ChatRoom في Django
5. ✅ عرض ملخص النتائج

## ملاحظات

- إذا كان Synapse في WSL، استخدم `http://localhost:8008` كعنوان السيرفر
- تأكد من أن Synapse يعمل قبل تشغيل الأمر
- الغرف الموجودة مسبقاً سيتم تخطيها (ما لم تستخدم `--force`)
