# دليل إعدادات البث المباشر

تم إضافة نظام إدارة البث المباشر والمواجهات الرياضية إلى السيرفر الخلفي.

## المميزات الجديدة

### 1. إدارة القنوات
- إضافة قنوات البث المباشر مع روابطها
- تحديد نوع البث (FLV, HLS, MPEG-TS, DASH, HTML5)
- رفع أيقونات للقنوات
- ترتيب القنوات حسب الأولوية

### 2. إدارة المواجهات
- إضافة مواجهات رياضية بين الفرق
- رفع شعارات الفرق
- تحديد وقت المباراة
- ربط المباراة بقناة البث المباشر
- تحديد القناة الناقلة

## كيفية الاستخدام

### 1. إضافة قناة بث مباشر

1. انتقل إلى لوحة الإدارة: `http://172.16.1.2:8000/admin`
2. اختر **قنوات البث المباشر** من القائمة
3. اضغط على **إضافة قناة بث مباشر**
4. املأ البيانات:
   - **اسم القناة**: مثل "القناة 1"
   - **رابط البث**: رابط البث المباشر
   - **نوع البث**: اختر من القائمة (FLV, HLS, MPEG-TS, DASH, HTML5)
   - **أيقونة القناة**: (اختياري) رفع صورة أيقونة
   - **وصف القناة**: (اختياري) وصف للقناة
   - **ترتيب القناة**: رقم الترتيب (الأقل يظهر أولاً)
   - **نشط**: تأكد من تفعيل القناة

### 2. إضافة مواجهة رياضية

1. انتقل إلى **المواجهات** من القائمة
2. اضغط على **إضافة مباراة**
3. املأ البيانات:
   - **اسم الفريق الأول**: اسم الفريق
   - **شعار الفريق الأول**: (اختياري) رفع شعار الفريق
   - **اسم الفريق الثاني**: اسم الفريق
   - **شعار الفريق الثاني**: (اختياري) رفع شعار الفريق
   - **وقت المباراة**: تاريخ ووقت المباراة
   - **القناة الناقلة**: اسم القناة الناقلة (اختياري)
   - **قناة البث المباشر**: اختر القناة المرتبطة (اختياري)
   - **ترتيب المباراة**: رقم الترتيب
   - **نشط**: تأكد من تفعيل المباراة

## APIs المتاحة

### 1. جلب القنوات
```
GET http://172.16.1.2:8000/api/live-channels
```

**الإرجاع:**
```json
[
  {
    "id": 1,
    "name": "القناة 1",
    "url": "https://example.com/stream.m3u8",
    "type": "hls",
    "icon": "http://172.16.1.2:8000/media/channels/icons/icon.png",
    "description": "وصف القناة",
    "order": 0
  }
]
```

### 2. جلب المواجهات
```
GET http://172.16.1.2:8000/api/matches
```

**الإرجاع:**
```json
[
  {
    "id": 1,
    "team1Name": "الفريق الأول",
    "team1Logo": "http://172.16.1.2:8000/media/matches/teams/team1.png",
    "team2Name": "الفريق الثاني",
    "team2Logo": "http://172.16.1.2:8000/media/matches/teams/team2.png",
    "matchTime": "2024-01-15 20:00:00",
    "channel": "القناة الرياضية",
    "liveChannelId": 1,
    "order": 0
  }
]
```

## صفحة البث المباشر

صفحة البث المباشر (`live/index.html`) الآن تعتمد على APIs من السيرفر الخلفي:

- **جلب القنوات**: يتم جلب القنوات تلقائياً من `/api/live-channels`
- **جلب المواجهات**: يتم جلب المواجهات تلقائياً من `/api/matches`
- **ربط المباريات بالقنوات**: عند النقر على مباراة مرتبطة بقناة، يتم تشغيل القناة تلقائياً

## ملاحظات مهمة

1. **تأكد من تشغيل السيرفر الخلفي** قبل فتح صفحة البث المباشر
2. **رابط API**: افتراضي `http://172.16.1.2:8000/api/` - يمكن تغييره في `live/scripts.js` و `live/index.html`
3. **الصور**: تأكد من رفع الصور في لوحة الإدارة لظهورها بشكل صحيح
4. **الترتيب**: استخدم حقل الترتيب لترتيب القنوات والمباريات حسب الرغبة

## الخطوات التالية

1. قم بتشغيل السيرفر الخلفي:
   ```bash
   cd backend
   python manage.py runserver
   ```

2. افتح لوحة الإدارة وأضف القنوات والمواجهات

3. افتح صفحة البث المباشر: `live/index.html`

4. استمتع بالبث المباشر!
