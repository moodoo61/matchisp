# تنظيم صفحة إدارة Django Admin

## نظرة عامة
تم تنظيم صفحة إدارة Django بشكل منظم حسب الأقسام التالية:

---

## 📋 الأقسام

### ⚙️ القسم العام
يحتوي على الإعدادات الأساسية للموقع:
- **إعدادات الموقع** (`SiteSettings`): إعدادات الموقع الشاملة

### 🔐 قسم صفحة تسجيل الدخول
يحتوي على جميع العناصر المتعلقة بصفحة تسجيل الدخول:
- **الإعلانات** (`Advertisement`): إدارة الإعلانات
- **الباقات** (`Package`): إدارة باقات الاشتراك
- **الروابط** (`Link`): الروابط السريعة
- **الشريط المتحرك** (`NewsTicker`): الأخبار المتحركة
- **الوكلاء** (`Agent`): معلومات الوكلاء

### 📺 قسم صفحة البث
يحتوي على كل ما يتعلق بصفحة البث المباشر:
- **الموجهات** (`Match`): إدارة المباريات والمواجهات
- **قنوات البث المباشر** (`LiveChannel`): إدارة قنوات البث

### 💬 قسم الشات
يحتوي على نظام الدردشة:
- **غرف الدردشة** (`ChatRoom`): إدارة غرف الدردشة
- **مستخدمو الدردشة** (`ChatUser`): إدارة المستخدمين
- **رسائل الدردشة** (`ChatMessage`): أرشيف الرسائل

## 🏗️ البنية التقنية

### الهيكل
```
backend/
├── api/                    # التطبيق الرئيسي (Models)
│   ├── models.py          # جميع النماذج
│   └── admin.py           # تعريفات Admin Classes
├── general/               # تطبيق القسم العام
│   ├── apps.py
│   └── admin.py
├── login_page/            # تطبيق قسم صفحة تسجيل الدخول
│   ├── apps.py
│   └── admin.py
├── streaming/             # تطبيق قسم صفحة البث
│   ├── apps.py
│   └── admin.py
└── chat/                  # تطبيق قسم الشات
    ├── apps.py
    └── admin.py
```

### التكوين
جميع التطبيقات مسجلة في `settings.py`:
```python
INSTALLED_APPS = [
    # ...
    'api',
    'general',
    'login_page',
    'streaming',
    'chat',
]
```

## ✨ المميزات

1. **تنظيم أفضل**: سهولة العثور على النماذج حسب السياق
2. **إدارة محسنة**: كل قسم منفصل عن الآخر
3. **قابلية التوسع**: سهولة إضافة أقسام جديدة
4. **رموز تعبيرية**: استخدام الإيموجي لتمييز كل قسم بصرياً

---

## 🔧 الصيانة

### إضافة نموذج جديد
1. أضف النموذج في `api/models.py`
2. أنشئ Admin Class في `api/admin.py`
3. سجل النموذج في التطبيق المناسب (مثلاً `general/admin.py`)

### إضافة قسم جديد
1. أنشئ مجلد جديد للقسم
2. أنشئ `__init__.py` و `apps.py` و `admin.py`
3. أضف القسم في `INSTALLED_APPS` في `settings.py`

---

## 📝 ملاحظات

- جميع النماذج موجودة في `api/models.py`
- Admin Classes معرفة في `api/admin.py`
- كل تطبيق يسجل النماذج المتعلقة به فقط
- لا يتم تسجيل النماذج في `api/admin.py` مباشرةً لتجنب التكرار
