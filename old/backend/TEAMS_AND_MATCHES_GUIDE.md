# نظام الفرق والمباريات - دليل الاستخدام

## 📋 نظرة عامة

تم تطوير نظام إدارة الفرق والمباريات ليشمل:
- **نموذج الفرق**: إدارة مركزية للفرق الرياضية (منتخبات/أندية)
- **نموذج المباريات المحدث**: ربط المباريات بالفرق + حساب حالة المباراة تلقائياً

---

## 🏆 نموذج الفرق (Team)

### الحقول
- **اسم الفريق**: اسم الفريق الرياضي
- **نوع الفريق**: 
  - `منتخب` 🏆
  - `نادي` ⚽
- **الشعار**: صورة شعار الفريق
- **نشط**: لإظهار/إخفاء الفريق

### الفوائد
1. **إدارة مركزية**: تعديل شعار أو اسم الفريق مرة واحدة يطبق على جميع المباريات
2. **منع التكرار**: لا حاجة لإدخال نفس الفريق في كل مباراة
3. **تنظيم أفضل**: فصل واضح بين المنتخبات والأندية

---

## ⚽ نموذج المباريات المحدث (Match)

### التغييرات الرئيسية

#### ✅ الحقول الجديدة
- **نوع المباراة**: اختيار بين (منتخبات/أندية)
- **الفريق الأول**: اختيار من قائمة الفرق المسجلة
- **الفريق الثاني**: اختيار من قائمة الفرق المسجلة

#### ❌ الحقول المحذوفة
- ~~اسم الفريق الأول~~
- ~~شعار الفريق الأول~~
- ~~اسم الفريق الثاني~~
- ~~شعار الفريق الثاني~~
- ~~القناة الناقلة~~ (استبدلت بـ قناة البث المباشر فقط)

### حساب حالة المباراة تلقائياً

يتم حساب حالة المباراة تلقائياً بناءً على الموعد:

#### 1. **قادمة** (Upcoming) - 🔵
```
- بعد X يوم
- بعد X ساعة
- بعد X دقيقة
```

#### 2. **جارية الآن** (Live) - 🔴
```
🔴 مباشر
```
- تظهر أثناء وقت المباراة (120 دقيقة من وقت البداية)

#### 3. **انتهت** (Finished) - ⚪
```
انتهت
```

### المنطقة الزمنية
- **المنطقة الزمنية**: تم تكوين المشروع للعمل مع `Asia/Riyadh` (+3 GMT)
- **موعد المباراة**: يتم حسابه تلقائياً حسب منطقتك الزمنية

## 🎨 صفحة الإدارة

### قسم الفرق
يظهر في: **📺 قسم صفحة البث > الفرق**

**المميزات**:
- عرض الأيقونات (🏆 منتخبات / ⚽ أندية)
- معاينة الشعار
- بحث بالاسم
- فلترة حسب النوع

### قسم المباريات
يظهر في: **📺 قسم صفحة البث > الموجهات**

**المميزات**:
- عرض المباراة: `الفريق الأول 🆚 الفريق الثاني`
- عرض الحالة بألوان:
  - 🔵 **قادمة** (أزرق)
  - 🔴 **جارية** (أحمر)
  - ⚪ **انتهت** (رمادي)
- autocomplete للبحث عن الفرق
- فلترة حسب نوع المباراة والوقت

## 💡 نصائح الاستخدام

### 1. إضافة فريق جديد
```
1. اذهب إلى: قسم صفحة البث > الفرق
2. اضغط "إضافة فريق"
3. أدخل:
   - اسم الفريق
   - نوع الفريق (منتخب/نادي)
   - رفع الشعار
4. احفظ
```

### 2. إضافة مباراة جديدة
```
1. اذهب إلى: قسم صفحة البث > الموجهات
2. اضغط "إضافة مباراة"
3. اختر:
   - نوع المباراة (منتخبات/أندية)
   - الفريق الأول (من القائمة)
   - الفريق الثاني (من القائمة)
   - الموعد
   - قناة البث
4. احفظ
```

### 3. تعديل فريق موجود
```
- عند تعديل اسم أو شعار فريق
- سيتم تحديثه تلقائياً في جميع المباريات
```
